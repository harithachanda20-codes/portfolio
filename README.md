# Chanda Haritha | Full Stack Java Developer Portfolio

A professional personal portfolio website showcasing my technical skills, projects, internships, certifications, resume, and contact information.

## Live Portfolio

🌐 https://harithachanda20-codes.github.io/portfolio/

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Java
- Spring Boot
- Spring MVC
- Hibernate / JPA
- JDBC
- PostgreSQL
- Docker
- Git & GitHub

## Features

- Responsive portfolio website
- About Me section
- Technical skills section
- Projects showcase
- Internship experience
- Certifications
- Resume
- LinkedIn and GitHub links
- Contact form connected to a Spring Boot backend

## Backend

The contact form is connected to a Spring Boot REST API.

### Backend Repository

https://github.com/harithachanda20-codes/portfolio-backend

### Backend API

https://portfolio-backend-z3z0.onrender.com

## Database

PostgreSQL is used to store contact form messages.

## Deployment

- Frontend: GitHub Pages
- Backend: Render
- Database: Render PostgreSQL
- Backend containerization: Docker
